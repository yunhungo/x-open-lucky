# 服务分组方案与交互

服务分组支持管理、批量归组、筛选折叠和按组查看访问统计。分组操作不修改域名、监听入口、证书、上游地址或容器配置。

## 数据与迁移

- 独立分组表保存名称、顺序和版本；Web 服务新增 `group_id`，空字符串表示未分组。
- SQL 迁移创建“基础网络、AI 服务、媒体下载、文件 / WebDAV、运维监控、其他工具”六个初始分组。它们与自定义分组具有相同的编辑能力。
- 已有服务默认未分组，不按域名或端口猜测用途。最新 NAS 清单可用于准备归组清单，但需要在端口迁移完成后再应用到生产。
- 删除分组时事务性地将成员转为未分组，保留服务其余字段。批量归组只更新分组字段，并逐项检查资源版本，避免覆盖并行上游调整。
- 名称去首尾空白，不允许空名、控制字符或同名组；最多 64 个分组。未分组是固定状态，不能删除、重命名或排序。
- 加密备份包含分组及关联，恢复时重新映射 ID；旧备份仍可恢复，服务归入未分组，当前分组定义保留。

## 页面交互

### Web 服务

工具栏保留搜索、状态、添加，增加分组筛选及“管理分组”。列表以分组标题分段，标题显示服务数、异常服务数及近 24 小时请求与平均响应头耗时；点击标题折叠，折叠偏好只保存在当前浏览器。搜索或指定分组时自动展开匹配结果，避免藏住搜索命中。

- 分组筛选包括全部、自定义分组与未分组，状态与搜索可以叠加；筛选写入 URL，可从概览、日志和详情跳转。
- 选择多项服务后出现紧凑的批量归组条。跨组筛选不保留隐藏选择，提交携带选择时的版本。
- 编辑服务时可以选择分组；筛选某组后添加服务默认选择该组。
- 空分组在管理器中保留，常规列表不占整块空白；筛选空组后可使用工具栏添加服务，或清除筛选。

### 分组管理

右侧抽屉展示有序列表，提供名称编辑、上移、下移和删除；排序按钮同时适用于触屏和键盘。底部可创建分组。删除前明确说明成员将转为未分组。保存或排序时禁用重复提交；失败保留输入并就地显示可恢复错误；成功仅显示短暂 toast。

### 概览、详情与日志

概览增加紧凑的分组摘要，可进入分组服务列表。选择某一分组后显示其访问趋势、请求数、4xx / 5xx、流中断及平均响应头耗时，并链接到分组日志。服务详情显示归属并可通过现有编辑入口调整。访问日志增加分组筛选，服务选项跟随分组范围，分页和错误筛选沿用现有行为。

## 统计与性能

- 分组统计按“当前成员”汇总既有服务小时桶；服务移组后，其保留期内历史随当前归属展示。删除服务后的历史仍在全局统计与日志中，但不归入任何现存分组。
- 请求总数求和，平均响应头耗时使用总耗时 / 请求量，不能平均各服务平均值。不存在真实请求时显示零请求和空耗时。
- 无匹配规则的请求只计入全局，避免把“未分组”与“未知域名”混淆。
- CPU、进程内存和容器内存仍表示整个 OpenLucky，不推算或虚构每组的资源占用。分组内性能指已观测的响应头耗时与错误情况。
- 新功能不增加代理请求路径的锁、数据库读取或采集字段。管理端批量读取现有服务桶完成聚合，禁止按每个分组分别轮询；日志使用当前成员 ID 作为索引筛选。

## 验收

覆盖旧数据迁移、分组 CRUD、排序冲突、批量归组原子性、删除后成员保留、旧 / 新备份、加权统计、未分组与未知域名隔离、日志分页及分组范围。浏览器覆盖桌面、390px 手机、暗色、筛选折叠、键盘排序、批量操作、失败输入保留与即时反馈。运行 `.myself/check.sh`，测试使用临时数据库和本地上游，不修改生产 DNS。
