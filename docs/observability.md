# 访问与性能观测

## 口径

- 请求统计覆盖到达 HTTP 代理处理器并返回响应头的请求，包括未匹配域名、HTTPS 跳转、HTTP/2 与协议升级。管理 API、健康检查和 TLS 握手失败不计入 Web 访问量。
- 每个请求在响应头就绪时计数一次。耗时是从代理开始处理到响应头就绪的时间，不包括下载正文或 WebSocket 连接寿命。5xx 为服务端错误，4xx 单独计数；错误率的分母是所有请求。
- 响应流、升级握手或隧道转发中断会增加独立诊断记录，以同一 `request_id` 关联，不重复增加请求量。正常客户端断开不作为应用错误。HTTP 升级返回 101 的记录代表握手成功，不代表隧道永久健康。
- 全站统计包括已删除服务和未匹配域名；单服务按稳定资源 ID 区分，改名不会清空历史，删除再新建是新服务。备份恢复重新生成 ID，因此恢复后的服务不会合并原服务统计。
- 默认展示当前小时及之前 23 个小时；7 天和 30 天同样采用自然小时桶。长期趋势在前端按 6 小时或 24 小时合并，空桶补零。
- Linux 进程 CPU 使用 `/proc/self/stat` 的用户态和内核态 CPU 时间差，一个核心占满为 100%，可以超过 100%。进程内存为 RSS；容器内存和上限来自 cgroup v1/v2，CPU 配额另行展示。采样每 5 秒一次，CPU 趋势保留最近 10 分钟；首个 CPU 样本及不支持的平台返回 `null`，界面显示 `—`。

## 容量与故障合同

| 数据 | 边界 |
| --- | --- |
| 访问明细 | 默认 7 天 / 20,000 条，先触及者生效 |
| 小时统计 | 30 天 / 100,000 个服务小时桶 |
| 内存队列 | 2,048 条普通记录 + 512 条错误记录；最多 1,024 个待写统计桶 |
| 字段 | 路径 512 字节、域名 253 字节、方法 16 字节、错误原因 160 字节；完整单条 JSON 不超过 4 KiB |
| 独立数据库 | `/data/telemetry.sqlite`，`max_page_count` 固定 64 MiB；配置数据库独立 |
| 事务临时空间 | DELETE journal 随事务删除，无长期 WAL；写事务可能额外使用不超过数据库大小量级的回滚日志空间 |
| 系统事件 | 最多 2,000 条，每条消息最多 2 KiB |
| 容器控制台 | Docker `json-file`，每文件 10 MiB，最多 3 个 |

代理仅更新有界内存，不等待数据库；每 5 秒批量落盘。队列溢出时各自淘汰最旧明细，错误有独立容量，统计在明细淘汰前独立累计。超过统计维度上限或持久化失败时也可能丢失统计，界面明确显示异常，不能把此时的统计当完整数据。

满盘、数据库忙等写失败不阻塞代理。失败批次计入丢弃计数，不无限重试堆积；尝试回收最旧一半诊断数据，后续周期重试。数据库页已分配空间可复用，不周期性执行阻塞式 VACUUM。按条数限制和页限制共同约束实际增长，不承诺一定保留满 7 天。正常停机完成代理排空后再写最后一批；断电或强杀最多丢失尚未持久化的队列。

`dropped_logs`、`dropped_buckets`、`write_failures` 统计本次进程运行期间的损失。概览出现持久提示，日志页“采集有丢失”可展开查看计数。批次持久化失败可能影响整个批次的日志与统计；只有内存明细溢出时，请求统计仍保持完整。

环境变量 `OPENLUCKY_ACCESS_DAYS` 接受 1–30，`OPENLUCKY_ACCESS_ROWS` 接受 1,000–100,000，修改 QNAP `runtime.env` 后重启本项目容器生效。非法配置拒绝启动。调大条数不扩大 64 MiB 页上限。

## 隐私与排障

访问日志只保存真实连接 IP、方法、不含查询参数的路径、规范化域名、入口、服务 ID、状态、阶段、耗时与固定错误原因。不会保存请求/响应头、Cookie、Authorization、正文或原始上游异常。路径本身仍属于访问数据；不要把凭据嵌入 URL 路径。

每个响应带有本代理生成的 `X-OpenLucky-Request-Id`，日志页可按 ID、路径、IP 或域名搜索；展开请求可查看 ID 和入口。界面导出仅包含当前页，避免一次拉取全部数据。所有观测 API 沿用管理员会话保护，查询参数使用绑定 SQL，单页最多 200 条。

数据库随 NAS 部署快照备份；可迁移配置备份不包含访问历史。遥测迁移在 `backend/telemetry_migrations` 独立版本化，不修改既有配置合同。

## 验证

Rust 测试覆盖高峰队列上限、错误预留容量、统计独立性、UTF-8 截断、按时间/数量清理、重启持久化和页限制、满库失败与后续恢复。协议测试使用临时数据库验证脱敏、真实代理错误、流中断、分页、筛选、认证和参数校验。浏览器测试覆盖服务详情、筛选、分页、主题和桌面/移动布局，不接触生产 DNS。
